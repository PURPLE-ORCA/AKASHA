# Akasha Capture

The WXT Manifest V3 extension for capturing images into Akasha. It uses an in-page capture panel and the `Save to Akasha` image context-menu action.

Video capture is postponed. The dormant browser observer is retained under `dormant/video-capture/` for historical reference and is excluded from extension builds.

See the [workspace README](../README.md) for OAuth setup and commands.
